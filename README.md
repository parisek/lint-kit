# lint-kit

Status: **planned**. This repository holds no code yet.

One Composer package for the Twig and PHPStan lint rules, shared by WordPress and Drupal projects:
a CMS-neutral core and one opt-in rule set per CMS.

The plan and the specification are in the issue: [portadesign/tailwind-base#874](https://github.com/portadesign/tailwind-base/issues/874).

An announcement will follow later.

Related: [`test-kit`](https://github.com/parisek/test-kit), the testing and comparison tool.
