# Architecture Decision Records

Short notes on decisions that shaped this repository. They record the reason, so a later reader does not have to guess it from the code.

Write one only when the decision is hard to reverse, surprising without context, and the result of a real trade-off. Propose it to the owner first. Format: Context, Decision, Consequences. One file for each decision: `NNNN-kebab-title.md`. Numbers are permanent.
